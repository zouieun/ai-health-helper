# 饮食健康常见问题与术语释义

本文件以问答与术语释义的形式，集中说明饮食健康与减肥相关的常见问题，便于快速查阅与应用。

## 常见问答

### 什么是真正的“健康饮食”？
- 健康饮食并非绝对禁食某类食物，而是强调营养素（碳水、蛋白质、脂肪）的均衡搭配与热量摄入的适度。
- 需要根据个人的基础代谢率（BMR）和日常活动量，动态调整饮食结构。

### 如何看懂食品的“营养成分表”？
- 重点关注“NRV%”（营养素参考值百分比），判断该食物占全天推荐摄入量的比例。
- 注意区分“每100g”与“每份”的热量，避免被小份量包装误导，重点防范“隐形糖”与“隐形钠”。

### 减肥期间可以不吃主食吗？
- 不建议完全断碳水。长期极低碳水会导致基础代谢下降、情绪暴躁、脱发及女性生理期紊乱。
- 建议将精米白面替换为粗粮（如燕麦、糙米、红薯），以平稳血糖并增加饱腹感。

### 如何进行有效的饮食记录？
- 善用饮食记录App，初步估算每日摄入热量（TDEE）。
- 建立“红黄绿”食物清单，避免凭感觉进食，关注蛋白质与膳食纤维的达标率。

## 术语释义

- **基础代谢率（BMR）**：指人体在清醒且极端安静状态下维持生命所需的最低热量消耗。
- **升糖指数（GI）**：反映食物引起人体血糖升高程度的指标，低GI食物更有利于减脂与血糖稳定。
- **隐形热量（Hidden Calories）**：指存在于烹饪油、沙拉酱、饮料及零食中，容易被忽视的高密度热量。
- **三大宏量营养素**：碳水化合物、蛋白质、脂肪，是人体获取能量的主要来源。
