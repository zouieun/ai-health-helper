# 减脂饮食方法与热量整理建议

本文件提供实操层面的饮食搭配方法，并针对日常热量数据的整理与记录给出建议。

## 饮食搭配方法

- **蛋白质优先**：每餐优先摄入优质蛋白（鸡胸肉、鱼虾、瘦牛肉、豆制品），保留肌肉并延长饱腹感。
- **主食粗细搭配**：将全天的碳水摄入集中在运动前后，或采用“先吃菜、再吃肉、最后吃主食”的进餐顺序。
- **外食应对策略**：外卖或餐厅就餐时，主动要求少油少盐，用清水涮去多余油脂，避开糖醋、红烧、干煸等高热量做法。

## 数据整理建议

- **建立个人食物库**：记录自己常吃食物的热量与宏量营养素，形成习惯后无需每餐精确计算。
- **每周复盘**：对比每周体重波动与饮食记录，若连续两周体重停滞，需重新评估摄入量（TDEE）是否准确。
- **关注比例而非绝对数值**：不必苛求精确到个位数的热量，关注每日碳水、蛋白质、脂肪的供能比例更为重要（如 4:4:2 或 5:3:2）。
