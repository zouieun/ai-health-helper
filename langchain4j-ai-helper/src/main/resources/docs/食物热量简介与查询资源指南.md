# 食物热量简介与查询资源指南

本文件集中介绍常见食物类别的热量特征，并提供便捷的查询工具与资源指南。

## 常见食物热量简介

- **高热量陷阱区（红灯区）**：坚果（约500-600大卡/100g）、油炸食品、烘焙甜点、奶茶与含糖饮料。
- **中等热量区（黄灯区）**：精制碳水（米饭、面条）、部分热带水果（榴莲、芒果）、红肉（猪牛羊肉）。
- **低热量优选区（绿灯区）**：绿叶蔬菜（约15-30大卡/100g）、低糖水果（莓果、柚子）、白肉（鱼虾、鸡胸肉）。

## 查询资源与工具

- **权威数据库**：推荐使用《中国食物成分表》标准版，获取最严谨的营养素数据。
- **主流App与小程序**：薄荷健康、Keep、食物库等，支持扫码查询包装食品热量与宏量营养素。
- **包装食品标签**：购买预包装食品时，务必查看背面的“营养成分表”，重点核对每100g能量，并自行换算为（千卡/kcal）。

## 注意事项

- 烹饪方式对热量影响极大：水煮、清蒸的食材热量极低，而煎炸炒烤会因吸油导致热量翻倍。
- 注意食物重量“生重”与“熟重”的换算关系（如100g生米煮熟后约为250g米饭），查询热量时需确保基准一致。
