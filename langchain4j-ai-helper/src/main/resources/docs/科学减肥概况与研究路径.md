# 科学减肥概况与研究路径

本文件概述科学减肥的核心逻辑，并梳理从认知到执行的健康减脂路径。

## 减肥核心概况

- **热量缺口是核心**：减肥的底层逻辑是“消耗热量 > 摄入热量”，但缺口不宜过大（建议每日300-500大卡），否则易引发基础代谢受损。
- **个体差异性强**：基因、肠道菌群、激素水平及生活习惯均会影响减脂效果，不存在普适的“完美食谱”。

## 减脂路径规划

- **阶段一：认知与评估**：计算个人BMI、体脂率，评估当前的饮食结构与作息。
- **阶段二：饮食结构调整**：遵循“蔬菜:蛋白质:主食 = 2:1:1”的餐盘法则，减少深加工食品摄入。
- **阶段三：行为习惯固化**：建立规律的进食时间，改善睡眠（睡眠不足会导致皮质醇升高，阻碍脂肪分解）。

## 常见误区

- 认为“出汗越多瘦得越快”，忽视减掉的是水分而非脂肪。
- 盲目追求快速掉秤，采取极端节食，导致肌肉流失与体重反弹（溜溜球效应）。
